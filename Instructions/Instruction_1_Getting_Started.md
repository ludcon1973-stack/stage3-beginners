## Пункт 1. Подготовка проекта

### Шаг 1: Форк репозитория

Чтобы начать "строительство", сначала необходимо создать "сборочный цех", а именно рабочую директорию, в которой будут все файлы проекта.  
Для этого необходимо скопировать текущий репозиторий в свой аккаунт. Сделать это можно при помощи кнопки `"Форк"` напротив названия репозитория. 

Форк — это копирование текущего состояния репозитория. Все изменения, которые произойдут в оригинальном репозитории после форка, не будут автоматически попадать в вашу копию. Проще говоря, вы берёте готовую основу и начинаете работать с ней независимо.

После форка рекомендуется создать отдельную ветку `develop`, чтобы не работать напрямую в основной ветке (`master` или `main`).

Это стандартная практика, которая позволяет:
- безопасно вносить изменения;
- проводить эксперименты без риска сломать основную версию;
- удобно организовать процесс разработки (особенно в команде).

Это как построить несколько ангаров, где в каждом можно создавать свою версию космолета, а затем выбрать лучший из них.

Создать ветку можно двумя способами:
1. **Через интерфейс GitVerse**  
(как это делалось во [вводном туре](https://it-marathon.21-school.ru/gitverse-onboarding?type=coding))
2. **Через терминал** после выполнения [Шага 2](#шаг-2-создание-структуры-папок)  
В папке с проектом выполните команду:  
```bash
git checkout -b develop
```  
Эта команда создаст новую ветку `develop` и сразу переключит вас на неё.

### Шаг 2: Создание структуры папок

Мы собирались построить себе цеха, но по итогу вся наша "фабрика" все еще, скажем так, в облаках. Было бы удобно все перенести на свое устройство, не так ли? Для этого необходимо форкнутый репозиторий склонировать с помощью SSH-ключа в нужное место на устройстве. По сути сделать копию.  
Инструкция: <http://gitverse.ru/docs/repositories/clone-a-repository>.  
А также про клонирование репозитория мы рассказывали во вводном курсе по GitVerse, его можно найти на карточке этапа!
В твоем "приземленном филиале космобазы", т.е. в склонированном репозитории, создай папку с названием проекта `cosmo_site`. Внутри создай следующие папки:
- `css` - здесь будут храниться все файлы стилей;
- `js` - здесь будет храниться JavaScript-код;
- `shared` - общая папка для всех медиафайлов.

Внутри папки `shared` создай две папки:
- `icons` - для иконок и SVG-изображений;
- `pictures` - для фотографий и сгенерированных картинок.

Вообще, что сейчас, что даже в конце этого этапа тебе может показаться, что создание подобной структуры папок излишне и даже бесполезно, но это только из-за количества используемых файлов. В реальных проектах (как в IT, так и в космической отрасли) оно может достигать нескольких десятков или даже сотен, и без подобной файловой структуры можно запутаться, так что это крайне полезная практика, которую стоит применять в любом проекте. Если над сбором космолета работает несколько разных команд, у каждого же должен быть свой кабинет, правда ведь? Тут тот же принцип, но с группами файлов.

>Кстати, напоминаем: не забудь добавить свой токен в файл .cm-token.

### Шаг 3: Генерация изображений с помощью ИИ

Чтобы наш сайт ожил, ему нужна "картинка". Для наполнения страницы визуальным контентом тебе потребуются три изображения на тему, связанную с Днем Космонавтики (портрет Юрия Гагарина, взлетающая ракета, а также картинка для пазла в игре "пятнашки"). Ранее их пришлось бы искать на просторах сети Интернет или даже заказывать их создание у специалистов, но сейчас всем доступны ИИ-инструменты, с использованием которых можно сделать все самому, причем крайне качественно.Будущее уже здесь! 

Например, очень хорошо подойдет нейросеть Kandinsky. Использовать ее можно бесплатно, просто авторизовавшись в **GigaChat** с использованием Сбер ID или с помощью мессенджеров (ссылка на GigaChat: <https://giga.chat>).

Попроси твоего "художника" нарисовать тебе нужные картины, скопировав следующие промпты в поле ввода:

Промпт для портрета Юрия Гагарина:
```
Парадный портрет Юрия Гагарина в скафандре, крупным планом. На шлеме видна надпись "СССР". У Гагарина добрая, знаменитая улыбка. За спиной размытое изображение земного шара и звездного неба. Стиль: реалистичная живопись мазками, винтажный эффект, мягкий свет, кинематографичное настроение, высокое качество, текстура холста.
```
Промпт для взлетающей ракеты:
```
Эпичный взлет космической ракеты "Восток" с космодрома Байконур. Ракета изображена снизу вверх (ракурс "вид из травы"), от нее исходит яркое пламя и клубы дыма. Цвета насыщенные: синий, оранжевый, золотой. На заднем плане видна огромная луна. Стиль: советский плакат про космос, ретро, высокая детализация, контрастно, вдохновляюще, патриотично.
```
Промпт для картинки пазла:
```
Задача: 
Создай квадратное, яркое и стилистически целостное изображение на космическую тему
Требования:
- формат (aspect ratio): `--ar 1:1`
- стиль: цифровой рисунок, яркий и красочный, sci-fi, преимущественно голубые и фиолетовые оттенки
- содержание: простая сцена с космическим сюжетом, например: космонавт, ракета, планета, инопланетянин. центральный объект сцены находится посередине и занимает основную часть изображения
- композиция: используй крупные понятные детали, равномерно распределяй их по изображению, избегай деталей по краям рисунка
```
Сохрани полученные изображения в папку `shared/pictures` с именами:
- `gagarin.jpeg` - портрет Гагарина;
- `rocket-launch.jpeg` - взлет ракеты;
- `space-puzzle.jpeg` - картинка для игры в пятнашки.

Позже изображения станут частью нашей космической истории!

### Шаг 4: Добавление готовых SVG-иконок

Теперь добавим на наш космодром два символа космической эры: спутник и ракету. Возьми предоставленные файлы `sputnik.svg` (изображение спутника) и `rocket.svg` (изображение ракеты). Перемести их в папку `shared/icons`. Эти иконки будут украшать наш сайт, создавая атмосферу полета.

Интересный факт: как ты мог заметить, данные изображения имеют особый формат - SVG.  
Это "Scalable Vector Graphics" — формат «масштабируемой векторной графики». Говоря простым языком, такие изображения имеют максимальное качество вне зависимости от размера (в то время как изображения в обычных форматах из-за пикселей и сжатия могут выглядеть размыто или даже деформироваться). Звучит по-волшебному, но магия здесь ни при чем, это чистейшая геометрия. Из-за своих свойств, кстати, их часто используют в качестве иконок и логотипов.
