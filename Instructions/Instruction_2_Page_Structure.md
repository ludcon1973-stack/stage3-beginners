## Пункт 2.  Создание файлов сайта

Создание сайта происходит с использованием специальных языков: `HTML` и `CSS`.  
Ты, возможно, слышал, что в IT используются языки программирования, но `HTML` и `CSS` ими не являются, `HTML` – язык разметки, а `CSS` – язык стилей.  
`HTML` создает разметку сайта, то есть структуру его элементов. `CSS` же определяет стили HTML-разметки, то есть добавляет оформление. Словно каркас звездолета, на который навешивают корпус и прочие детали.  
Например, `HTML` создает квадрат с текстом внутри, а `CSS` делает этот квадрат нужного размера, а текст – нужного цвета.

Кстати, создание сайта с использованием `HTML+CSS` называют **версткой**.

Логично, что удобнее разделить разметку и стили, поэтому стоит создать два отдельных файла, в одном будет структура сайта, а в другом – его оформление.

### Шаг 1: Создание HTML-файла

Для того, чтобы начать работу, необходимо использовать специализированный инструмент разработки. Точно так же неудобно, как использование шуруповерта для забивания гвоздей, и использование редакторов документов для написания кода. Для этого существуют специальные программ-инструменты. Мы рекомендуем тебе в свой инвентарь добавить "мультитул" под названием "Visual Studio Code". Это легковесный, но в то же время мощный инструмент для разработки. Для его настройки выполни следующие шаги:
- установи программу:
	- для Windows: скачай [установочный файл с официального сайта](https://code.visualstudio.com/docs/setup/windows), установи с помощью мастера установки;
	- для Linux: используй менеджер установки Ubuntu Software или скачай нужный дистрибутив с [сайта](https://code.visualstudio.com/Download)  
  В этом случае также нужно в консоли выполнить команду 
  ```bash
  sudo apt install ./<file>.deb
  ```
  где `<file>` – это скачанный дистрибутив
	- для macOS: скачай нужный файл с [официального сайта](https://code.visualstudio.com/docs/setup/mac), установи его, перенеси VS Code в папку с приложениями и добавь программу в Dock.
- запусти программу;
- открой в программе папку проекта с использованием опции "Файл" -> "Открыть…".

Создай новый файл и сохрани его в папке `cosmo_site` под именем `index.html`. Это будет главная страница нашего космического путешествия!

Вставь в файл `index.html` базовую структуру `HTML`:
```html
<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  <title>С Днем космонавтики!</title>
  <link rel="stylesheet" href="css/styles.css">
</head>
<body>


</body>
</html>
```

#### Что здесь происходит

Сейчас вы создали заготовку HTML-документа — основу будущего сайта.  
В ней указано:
- что используется HTML (`<!DOCTYPE html>`)
- язык страницы — русский (`lang="ru"`)
- метаданные:
  - кодировка (`UTF-8`)
  - адаптивность (`viewport`)
  - заголовок страницы (`title`)
  - подключение стилей (`css/styles.css`)

> #### Немного про теги HTML
> HTML строится из тегов — это «кирпичики», из которых создаётся структура сайта.
> * Тег открывается и закрывается: 
> ```html
> <tag></tag>
> ```
> * Теги идут последовательно: 
> ```html
> <tag1></tag1>
> <tag2></tag2>
> ```
> * Или вкладываются друг в друга:
> ```html
> <tag2>
>   <tag1></tag1>
> </tag2>
> ```

> #### Важно
> Все элементы страницы нужно размещать внутри тега `<body>`:
> ```html
> <body>
>  <!-- Здесь содержимое сайта -->
> </body>
> ```

### Шаг 2: Создание CSS-файла

В папке `css` создай файл `styles.css`. Пока оставь его пустым. Сюда мы будем добавлять все стили по мере создания страницы, с его помощью скоро мы наполним сайт цветами и формами!

Вообще, есть несколько способов добавления стилей на сайт, например, через тег `style`, или через атрибут "style" в самом теге, но чаще всего подобные решения непрактичны, так как при больших объемах стили и разметка начнут перемешиваться и мешать друг другу. Напоминаем, несколько команд – несколько кабинетов, и никто друг другу не мешает и в "гости" просто так не ходит. Кроме того, иногда удобно создать несколько файлов стилей, чтобы, например, разграничить их по смыслу.

Сами же стили добавляются:
- к типу тега (тегам одного типа);
- к классу тегов (о чем подробнее будет рассказано далее);
- к конкретному тегу по `id`;
- по универсальному селектору ко всем тегам (`*`);
- по псевдоклассам и псевдоэлементам (например, только к тем, на который наведена мышь, или только к тексту конкретно в плейсхолдере и т.п.).

## Пункт 3. Добавление декоративных элементов на фон

Перед тем, как добавлять основное содержимое сайта, стоит создать ему завораживающий фон. С ним нельзя будет взаимодействовать, но зато он сможет выполнять декоративную функцию, улучшая внешний вид сайта. Самим своим существованием он будет создавать для пользователя ту самую атмосферу звезд и космического путешествия!

### Шаг 1: Создание разметки декоративных элементов на фон

Добавим основные элементы. Они создадут ощущение бескрайнего космоса: вращающиеся орбиты, падающая комета и планеты. Вставь в `index.html` внутрь тега `body` следующий блок:
```html
<div class="orbit"></div>
<div class="orbit-two"></div>
<div class="orbit-three"></div>
<div class="comet"></div>
<div class="planet"></div>
```
Как ты мог заметить, тут у каждого тега `div` есть т.н. класс. Его можно использовать для визуального выделения принадлежности определенных тегов к какому-нибудь классу, то есть к определенному типу. Кроме того, как и обозначалось раньше, к каждому классу можно создать отдельные стили, то есть с их помощью можно оформлять одинаковые теги по-разному (в отличие от обычных стилей по типу тега, где все теги `div` стали бы одинакового оформления). Кроме того, один и тот же класс можно дать разным тегам, что также удобно для оформления стилями (в отличие от создания стиля по конкретному `id`, что оформит лишь только один определенный блок, т.к. `id` должен быть уникальным). По сути классы как бирки, вот видишь ты члена экипажа с надписью "Отдел механиков", и уже что-то про него знаешь по этой бирке.

Можно было заметить также, что сейчас использовался тег `div`. Это основной тег, по сути обычный блок (прямоугольная область). Благодаря своей простой универсальности он является фундаментом для почти любой разметки. Как и космолет не построить без титана, так и сайт не создать без `div`. Тем не менее, В `HTML`, помимо этого тега, есть множество других. Какую-то часть из них мы будем использовать далее. Про основные будет рассказано отдельно в рамках данной инструкции, однако, если есть желание разобраться со всеми используемыми тегами, или даже интересно узнать про какие-то еще, смело обращайся к документации из сети Интернет, например: <https://htmlbook.ru/html>. Да, иногда написанная другими людьми неофициальная спецификация может быть сродни контакту с инопланетной жизнью, но если чуть разобраться, полученная информация может быть крайне полезной.

### Шаг 2: Добавление стилей для фоновых элементов

Стили зададут внешний вид орбитам, комете и планете. Добавь в файл `styles.css` код, который отвечает за базовые переменные и оформление фона:
```css
:root {
  --bg: #08142d;
  --bg-deep: #030816;
  --red: #d62828;
  --gold: #f7d774;
  --gold-soft: #f1c75a;
  --cream: #fff5d6;
  --white: #f8fbff;
  --blue: #73c7ff;
  --shadow: 0 20px 60px rgba(0, 0, 0, 0.35);
  --panel: rgba(9, 24, 48, 0.72);
  --line: rgba(255, 245, 214, 0.16);
}

* {
  box-sizing: border-box;
}

html {
  scroll-behavior: smooth;
}

body {
  margin: 0;
  font-family: "Trebuchet MS", "Arial", sans-serif;
  color: var(--cream);
  background:
    radial-gradient(circle at 20% 20%, rgba(115, 199, 255, 0.15), transparent 30%),
    radial-gradient(circle at 80% 10%, rgba(247, 215, 116, 0.13), transparent 24%),
    radial-gradient(circle at 50% 80%, rgba(214, 40, 40, 0.18), transparent 34%),
    linear-gradient(180deg, var(--bg) 0%, #071020 48%, var(--bg-deep) 100%);
  min-height: 100vh;
  overflow-x: hidden;
  position: relative;
 max-width: 1200px;
margin-left: auto;
 margin-right: auto;
padding-bottom: 25px;
}

body::before {
  content: "";
  position: fixed;
  inset: 0;
  pointer-events: none;
  z-index: 0;
  background-image: 
    radial-gradient(circle, rgba(255, 255, 255, 0.95) 0 1px, transparent 1.5px),
    radial-gradient(circle, rgba(247, 215, 116, 0.7) 0 1px, transparent 1.7px),
    radial-gradient(circle, rgba(115, 199, 255, 0.8) 0 1px, transparent 1.6px);
  background-size: 180px 180px, 240px 240px, 320px 320px;
  background-position: 0 0, 60px 90px, 120px 40px;
  opacity: 0.6;
  animation: starsFloat 30s linear infinite;
}

body::after {
  content: "";
  position: fixed;
  inset: 0;
  pointer-events: none;
  z-index: 0;
  background:
    repeating-linear-gradient(
      90deg,
      transparent 0 36px,
      rgba(255, 255, 255, 0.02) 36px 37px
    ),
    repeating-linear-gradient(
      0deg,
      transparent 0 36px,
      rgba(255, 255, 255, 0.02) 36px 37px
    );

}

@keyframes starsFloat {
  from { transform: translateY(0); }
  to { transform: translateY(180px); }
}
```
Как можно заметить, чтобы задать стиль, необходимо указать тег/класс/id, после открыть фигурные скобки, и в них через точку с запятой перечислить необходимые атрибуты и их значения.  

В `CSS`, помимо представленных атрибутов, есть множество других. Какие-то являются общими и универсальны для всех тегов, какие-то уникальны для конкретного.  
Какую-то часть из них мы будем использовать далее. Про основные будет рассказано отдельно в рамках данной инструкции, однако, если есть желание разобраться со всеми используемыми атрибутами, или даже интересно узнать про какие-то еще, можно воспользоваться документацией из сети Интернет, например: <https://htmlbook.ru/css>.  
Но, помни, атрибутов в `CSS` больше, чем тегов в `HTML`. У ракет, например, тоже, что форма, что принцип работы примерно один и тот же у всех компаний, а вот их покрас, планировка внутри, стиль скафандров и т.д. – все отличаются.  
Тут примерно тот же принцип, свободы и потребности в создании стилей больше, чем разметки, поэтому CSS-атрибутов больше, чем тегов.

Обрати внимание на такие важные атрибуты, как:
- `background-color` — цвет фона блока тега;
- `position` — позиция блока тега;
- `z-index` — положение по глубине (кстати, именно из-за того, что значение там 0 все эти блоки будут на фоне, и не будут мешать основным блокам далее, ведь по-умолчанию все на 1);
- `margin` — отступы от границ блока тега снаружи;
- `width`/`height` — ширина/высота блока тега;
- `min` / `max`-`width` / `height` — минимально/максимально возможная высота/ширина блока тега;
- `opacity` — прозрачность.

### Шаг 3: Добавление стилей для орбит и небесных тел

А теперь — магия анимации! Эти стили заставят наши орбиты вращаться, а планеты — "жить" на экране. Добавь следующий код в `styles.css`:
```css
.orbit, .orbit-two, .orbit-three {

  border: 1px dashed rgba(255, 255, 255, 0.12);
  border-radius: 50%;
  pointer-events: none;
  z-index: 0;
}

.orbit {
  width: 72vw;
  height: 72vw;
  max-width: 900px;
  max-height: 900px;
  top: -22vw;
  right: -18vw;
  animation: spin 38s linear infinite;
}

.orbit-two {
  width: 52vw;
  height: 52vw;
  max-width: 680px;
  max-height: 680px;
  bottom: -14vw;
  left: -8vw;
  animation: spinReverse 28s linear infinite;
}

.orbit-three {
  width: 32vw;
  height: 32vw;
  max-width: 420px;
  max-height: 420px;
  top: 24vh;
  left: 6vw;
  animation: spin 20s linear infinite;
}

@keyframes spin {
  from { transform: rotate(0); }
  to { transform: rotate(360deg); }
}

@keyframes spinReverse {
  from { transform: rotate(360deg); }
  to { transform: rotate(0); }
}

.sputnik, .planet, .comet {
  position: fixed;
  pointer-events: none;
  z-index: 0;
  filter: drop-shadow(0 0 18px rgba(247, 215, 116, 0.35));

.planet {
  bottom: 12vh;
  left: 8vw;
  width: 120px;
  height: 120px;
  border-radius: 50%;
  background: radial-gradient(circle at 32% 30%, #ffeeb2, #f7d774 24%, #ca9d34 55%, #7c5413 100%);
  box-shadow: 0 0 40px rgba(247, 215, 116, 0.25);

.planet::after {
  content: "";

  border-radius: 999px;
  background: linear-gradient(90deg, transparent, rgba(255, 255, 255, 0.55), transparent);
  transform: rotate(-12deg);
  opacity: 0.8;
}

.comet {
  top: 16vh;
  left: -20vw;
  width: 220px;
  height: 4px;
  background: linear-gradient(90deg, transparent, rgba(255, 255, 255, 0.95), rgba(115, 199, 255, 0.2));
  transform: rotate(12deg);

  opacity: 0.8;

@keyframes pulsePlanet {
  0%, 100% { transform: scale(1); }
  50% { transform: scale(1.06); }

@keyframes cometFly {
  0% { transform: translateX(0) translateY(0) rotate(12deg); opacity: 0; }
  10% { opacity: 1; }
  70% { opacity: 1; }

```
Стоит заметить, что здесь, в отличие от прошлой части, в основном задаются стили для классов, а не типов тегов (и псевдоклассов), как в предыдущем. Для этого, как можно было понять, нужно поставить точку и затем только уже написать название класса.

Тут также стоит обратить внимание на следующие атрибуты, некоторые из которых, кстати, уже были нами использованы, но тут это более наглядно видно:
- `border` — настройки границ блока тега;
- `border-size` — размер границ блока тега;
- `border-radius` — скругление границ;
- `transform` — изменение внешнего вида блока тега (в данном случае поворот через `rotate`);
- `animation` — задание блоку тега анимации (отдельно через `@keyframes`).

Потихоньку расширяем наш "арсенал" атрибутов.

## Пункт 4. Добавление спутника на страницу

### Шаг 1: Создание разметки для спутника

Этот элегантный спутник будет плавно парить в правом верхнем углу, создавая ощущение бесконечного движения в космосе. Вставь в `index.html` после блока с планетой:
```html
<img src="shared/icons/sputnik.svg" class="sputnik" alt="Спутник">
```
Здесь используется тег `<img>` — он предназначен для добавления изображений на страницу.

**Основные атрибуты:**
* `src` — путь к изображению
(в данном случае: `shared/icons/sputnik.svg`)
* `class` — имя класса для стилизации через CSS (`sputnik`)
* `alt` — альтернативный текст (показывается, если изображение не загрузилось)

### Шаг 2: Добавление стилей для спутника

Добавь в `styles.css` код, который задаст положение и анимацию для спутника, придадим нашему спутнику идеальное положение и размер:
```css
.sputnik {
  top: 12vh;
  right: 16vw;
  width: 52px;
  animation: drift 14s ease-in-out infinite;
}

@keyframes drift {
  0%, 100% { transform: translateY(0) rotate(-8deg); }
  50% { transform: translateY(16px) rotate(6deg); }
}
```
Заметил, как мы используем разные единицы измерения для размеров? Давай разберемся, чтобы ты был готов к любым масштабам:
- абсолютные:
	- `px` — пиксели;
	- `cm` — сантиметры;
	- `mm` — миллиметры;
	- `in` — дюймы;
	- `pt` — типографские пункты;
	- `pc` — пика.
- относительные:
	- `z%` — процент от родительского тега;
	- `em` — от размера шрифта родительского тега;
	- `rem` — от размера шрифта корня;
	- `vw` — 1% от ширины страницы;
	- `vh` — 1% от высоты страницы;
	- `vmin` / `vmax` — минимальное/максимальное из `vw` и `vh`;
	- `ch` — ширина символа «0»
	- `ex` — высота строчной буквы «x»

Этот набор единиц измерения вполне достаточен для создания сайта. Правда, для постройки ракеты, и уж тем более ориентации в космическом пространстве, его, все-таки, недостаточно. Ну, кто знает, быть может, когда-нибудь в HTML добавят световые годы.
